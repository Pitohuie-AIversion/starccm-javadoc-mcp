## 2024-11-07 - WPF UI Accessibility
**Learning:** This project uses a Windows WPF GUI configured via XAML. Accessibility for WPF UI is handled using `AutomationProperties.LabeledBy` and `AutomationProperties.Name` attributes rather than standard HTML ARIA attributes.
**Action:** When improving accessibility in WPF UI, use `AutomationProperties` attributes instead of HTML ARIA attributes.
